## 01. Простые числа

```python
n = int(input())
primes = []
x = 2
while len(primes) < n:
    if all(x % p != 0 for p in primes):
        primes.append(x)
    x += 1
print(primes[-1])
```

**Пояснение.** Перебираем числа начиная с 2. Число простое, если оно не делится ни на одно из уже найденных простых. Такие числа складываем в список, пока в нём не станет `n` элементов. Последний элемент списка и есть `n`-е простое число.

## 02. Мама Дяди Федора

```python
n = int(input())
a = input().split()
seen = set()
ans = n
for i in range(n):
    seen.add(a[i])
    if len(seen) == 3:
        ans = i + 1
        break
print(ans)
```

**Пояснение.** Идём по дням и записываем номера платьев в множество `seen`. Как только в нём оказались все три номера, мама может уезжать. Ответ — номер этого дня (`i + 1`). Если до конца сезона так и не набралось три разных платья, ответ — `n`, последний день.

## 03. Удаление буквы

```python
from string import ascii_lowercase

s = input()
best = max(ascii_lowercase, key=s.count)
print(s.replace(best, ""))
```

**Пояснение.** Чем чаще буква встречается в слове, тем сильнее слово сократится при её удалении. Поэтому находим самую частую букву: `max` по алфавиту с ключом `s.count`. Затем удаляем её из строки через `replace`. В условии гарантируется минимум две разные буквы, поэтому слово не пропадёт целиком.

## 04. Качество пароля

```python
rows = ["1234567890", "qwertyuiop", "asdfghjkl", "zxcvbnm"]
n = int(input())
for _ in range(n):
    p = input()
    ok = all(any(c in row for c in p) for row in rows)
    print("strong" if ok else "weak")
```

**Пояснение.** Пароль надёжный, если в нём есть хотя бы один символ из каждого ряда клавиатуры. Для каждого ряда проверяем, что в пароле найдётся символ из этого ряда (`any`). Затем проверяем, что это верно для всех четырёх рядов (`all`). Если да, выводим `strong`, иначе `weak`.

## 05. Игра в Дурака

```python
ranks = ["6", "7", "8", "9", "10", "Jack", "Queen", "King", "Ace"]
trump = input()
n = int(input())
result = []
for _ in range(n):
    r1, s1 = input().split()
    r2, s2 = input().split()
    if s1 == s2:
        ok = ranks.index(r2) > ranks.index(r1)
    else:
        ok = s2 == trump
    result.append("1" if ok else "0")
print(" ".join(result))
```

**Пояснение.** Список `ranks` хранит достоинства по возрастанию, поэтому индекс в нём показывает «силу» карты. Для каждого отбоя читаем две карты: атакующую (`r1`, `s1`) и отбивающую (`r2`, `s2`). Если масти одинаковые, отбой верный, когда достоинство второй карты выше. Если масти разные, отбой верный только тогда, когда отбивающая карта козырная. Результаты собираем в список и выводим через пробел.
