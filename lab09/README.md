### Задание 1 **(2)**
*Рассмотрим следующую программу.*
```
d = {'sep': ',' , 'end': '\n'}
l = ['Утопия', 14, 'Вселенная', 25]
print (l, d)
print (*l, d)
print (*l, *d)
print (*l, **d)
```
*Решение*

Что выведет программа:

```
['Утопия', 14, 'Вселенная', 25] {'sep': ',', 'end': '\n'}
Утопия 14 Вселенная 25 {'sep': ',', 'end': '\n'}
Утопия 14 Вселенная 25 sep end
Утопия,14,Вселенная,25
```

Тут вся суть в звёздочках при вызове функции.

1. `print(l, d)`. Без звёздочек в `print` уходят два аргумента: сам список и сам словарь. Они печатаются целиком, со скобками, через пробел.
2. `print(*l, d)`. Одна `*` перед списком «раскрывает» его, и каждый элемент передаётся как отдельный аргумент. Получается 4 элемента списка и словарь целиком. Элементы идут без скобок, а словарь печатается как был.
3. `print(*l, *d)`. Если раскрывать словарь одной `*`, то берутся только его ключи. Поэтому в конце напечатались слова `sep` и `end`.
4. `print(*l, **d)`. Две `**` раскрывают словарь в именованные аргументы, то есть это то же самое, что `print(*l, sep=',', end='\n')`. Значит, элементы печатаются через запятую без пробелов, а в конце ставится перевод строки (он и так стоит по умолчанию).

### Задание 3 **(1)**

*Задан список* **lst** *из натуральных чисел*. *Напишите фрагмент
программы, состоящий из одного вызова функции* **max**, *который найдет в этом списке число с максимальным
числом единиц в двоичной записи.* 

*Многоточие надо заменить на лямбда-функцию, использующую фукцию* **bin** *и метод строк* **count**.

*Пример работы приводится ниже.*
```
>>> lst = list(range(6000 ,7000))
>>> ans = max(lst,...)
>>> print(ans)
6143
```

*Решение*

```python
lst = list(range(6000, 7000))
ans = max(lst, key=lambda x: bin(x).count('1'))
print(ans)
```

Результат:

```
6143
```

`bin(x)` переводит число в строку с двоичной записью, например `'0b1011111111111'`. Метод `count('1')` считает в ней единицы. Параметр `key` говорит функции `max`, что сравнивать надо не сами числа, а количество единиц. У числа 6143 их 12, это максимум для диапазона.

### Задание 4 **(2)**

*Запишите фрагмент программы, которая упорядочит список слов
по длине, а при равенстве длины - лексикографически. Сортировка
должна состоять из одного вызова метода* **sort**.

*Пример работы приводится ниже.*

```
>>> lst = ['hello', 'hell', 'bye', 'world', 'bybye']
>>> lst.sort (...)
>>> print (lst)
['bye', 'hell', 'babye', 'hello', 'world']
```

*Решение*

```python
lst = ['hello', 'hell', 'bye', 'world', 'bybye']
lst.sort(key=lambda w: (len(w), w))
print(lst)
```

Результат:

```
['bye', 'hell', 'bybye', 'hello', 'world']
```

В `key` возвращается пара `(длина, слово)`. Python сравнивает пары по очереди: сначала по первому элементу (длине), а если длины равны, то по второму (само слово, то есть по алфавиту).
